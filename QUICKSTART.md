# Quick Start Guide

## 🚀 Get Started in 3 Steps

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Choose Your Path

#### Option A: Run the Complete Pipeline (Recommended First Time)
```bash
jupyter notebook notebooks/complete_pipeline.ipynb
```
Then run all cells to:
- Load and explore the data
- Train all models
- Save the best model

#### Option B: Launch the Dashboard Directly
```bash
streamlit run app/streamlit_app.py
```
Then click "Load Data & Model" in the sidebar.

### Step 3: Explore!
- Make predictions
- Analyze model performance
- Explore geographic visualizations
- Compare different models
